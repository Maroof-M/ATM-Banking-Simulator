# ATM-Banking-Simulator
A simple, menu-driven ATM Banking Simulator developed using the C programming language. Features include password verification, balance enquiry, deposits, withdrawals, transaction tracking and account summaries.

This project was built as part of my journey into learning C programming and understanding how programming concepts can be combined to develop practical applications.

## Features

- Password verification
- Account balance enquiry
- Deposit money
- Withdraw money
- Insufficient balance validation
- Transaction tracking
- Account summary
- Interactive ATM menu
- Exit functionality

## Programming Concepts Used

- Variables and data types
- User input and output (`scanf()` and `printf()`)
- Arithmetic operators
- Relational operators
- Conditional statements (`if-else`)
- `switch-case`
- `while` loop
- Increment operators
- Logical program flow and validation

## Requirements

- A C compiler (GCC recommended)
- Any code editor or IDE

## How to Compile and Run

Using GCC:
gcc ATM_Simulator.c -o ATM_Simulator

Run on Windows:
ATM_Simulator.exe

Run on Linux:
./ATM_Simulator

## Note

This is an educational project created for learning and practising C programming. It is not intended for real banking transactions or secure financial operations.
